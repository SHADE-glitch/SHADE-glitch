## Backend & AI applications

- **AI-Interview-Practice-and-Feedback-System** — AI mock-interview copilot.
  Spring Boot 3 + Spring AI (Qwen) multi-turn interviews, RAG knowledge base,
  agent tool loop, SSE streaming, RabbitMQ async report generation.
  *(private — code available on request)*
- **Local-life-service-platform** — Dianping-style local-life platform. Redis

## Open source & tooling

- **[opencode-skill-tracker](https://github.com/SHADE-glitch/opencode-skill-tracker)**
  — OpenCode plugin + TUI that records skill / MCP / plugin tool usage into a
  local SQLite database. No network, no message bodies.
- **[notification-grouper](https://github.com/SHADE-glitch/notification-grouper)**
  — GNOME Shell 50 extension that folds notifications from the same app into one stack.
- **GNOME extension maintenance forks** — keep the upstream feature set and fix
  latent crashes, leaks and power issues:
  [burn-my-windows](https://github.com/SHADE-glitch/burn-my-windows) ·
  [copyous](https://github.com/SHADE-glitch/copyous) ·
  [macos-dock](https://github.com/SHADE-glitch/macos-dock) ·
  [fast-translate](https://github.com/SHADE-glitch/fast-translate)
